# TheGentlemen for Export

Official website for **TheGentlemen for Export** — an Egyptian B2B frozen foods exporter delivering premium IQF vegetables, fruits, and French fries to global markets.

## Pages

- **Home** — Brand overview and featured products
- **About** — Company story, values, and mission
- **Products** — Full product catalogue (French fries, vegetables, fruits)
- **Export** — Markets, logistics, and certifications
- **Contact** — B2B inquiry form

## Tech

Pure HTML5, CSS3, and vanilla JavaScript. No frameworks, no build step.

## Setup

Before going live, replace the following in `contact.html`:
- `YOUR_WEB3FORMS_ACCESS_KEY` — add your [Web3Forms](https://web3forms.com) key
- Social media links in all footers — replace `href="#"` with real profile URLs
